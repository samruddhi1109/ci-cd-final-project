
# ci-cd-final-project

## Project Name
CI/CD Final Project

## Project Description
This project demonstrates Continuous Integration and Continuous Deployment (CI/CD) using GitHub Actions and OpenShift Pipelines.

## Technologies Used
- Python
- GitHub Actions
- flake8 for code linting
- nose for unit testing
- OpenShift Pipelines
- Tekton
- Buildah

## Features
- Automated code linting
- Automated unit testing
- CI/CD pipeline execution
- Application build and deployment

## Testing
The GitHub Actions workflow runs flake8 for linting and nose for unit testing.
